Radically Engineered.

PlexusDB sheds legacy database layers to interface directly with modern storage arrays, dropping costs while maxing IOPS.

Hardware-Aware I/O

Dynamically probes /sys/block to detect local architecture constraints. Completely bypasses the kernel page cache via io_uring + O_DIRECT.

LSM-Tree

Full leveled compaction (L0–L6). Integrated Bloom filters with zstd compressed memory blocks.

SWIM Gossip

Peer-to-peer membership discovery. Deterministic O(log n) convergence instantly without Zookeeper or Etcd.

S3 Infinite Cold-Tiering

Exceed local threshold limits dynamically. Frozen L6 SSTables safely and automatically offload to any S3-compatible backend (AWS, R2, MinIO) for infinite capacity.

Ergonomic Rust Client.

Built natively for Rust environments. Enjoy typed queries, strict namespace isolation, iterator range scans, and blazing fast gRPC batch operations out of the box.

tokio tonic tracing
main.rs 
use plexus_client::PlexusClient;

#[tokio::main]
async fn main() -> Result<(), plexus_client::Error> {
    // Zero-overhead gRPC connectivity
    let client = PlexusClient::connect("http://127.0.0.1:9090").await?;

    // Strictly isolated namespaces
    let users = client.namespace("users");

    // Optimized Pipeline Batches
    users.batch_put([
        ("bob",   b"viewer".as_slice()),
        ("carol", b"editor".as_slice()),
    ]).await?;

    // Iterator Range Scans
    let results = users.scan("a".."z", 100).await?;

    Ok(())
}
